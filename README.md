# Thoracentes Zeus β デモ画面

胸部 CT から作った 3D モデルを AR グラスで患者の体表に重ねる、Thoracentes Zeus β（研究開発中）の流れを説明するデモです。ブラウザで動きます。

> **ご注意**
> 本デモには研究開発中の未承認機能が含まれます。未承認機能は販売・授与の対象ではありません。
> 患者情報・CT 画像・3D モデル・数値はすべて架空のデータ（プログラムで作った合成ファントム）です。診断・治療には使用できません。

## デモの流れ

| ステップ | 画面 | 内容 |
|---|---|---|
| はじめに | ページ | 製品の概要。「CTを撮る、マーカを確認する、範囲をなぞる、そして見る」 |
| メイン画面 | PCアプリ「Zeus」 | 「1 新規データ追加」「2 マーカ・関心領域」「3 端末への転送」 |
| 1 新規データ追加 | PCアプリ | PACS（DICOM Gateway）または CD-ROM からの取込、体位選択 |
| 1 3D構成 | PCアプリ | 3D モデルの生成（処理時間は短縮して表示）、2D 画像の確認（縦隔／肺野） |
| 2 マーカ確認 | PCアプリ | 3 点の CT マーカ（右鎖骨中線・左鎖骨中線・剣状突起）の確認・やり直し |
| 2 関心領域 | PCアプリ | ペン・消しゴムで関心領域を描く、2点ライン、深度計測 |
| 3 端末への転送 | PCアプリ | Meta Quest 3 / XREAL（Beam Pro）/ iPad・iPhone へ転送 |
| AR表示 | ARグラスの視野 | 3 点位置合わせ、プリセット、透過度、3D 表示 ON/OFF、ミラーリング |
| 研究開発中の機能 | ページ | ヘッダーの「研究開発機能を表示」を ON にしたときだけ表示 |
| まとめ | ページ | 振り返り |

ヘッダーの **▶ ガイドツアー** を押すと、全画面を自動で操作しながら案内します（展示向け）。途中で止めるときは「■ 停止」か Esc キーを押します。

## 動かし方

Node.js 20 以降が必要です。

```bash
npm install
npm run dev            # 開発サーバー（http://localhost:5173）
npm run build          # dist/ に出力（静的サイトとして配置できます）
npm run build:single   # dist-single/index.html の 1 ファイルに出力（オフライン展示用）
```

`npm run build:single` で作った `dist-single/index.html` は、外部への通信なしで動きます。ファイルをダブルクリックしてブラウザで開くだけで使えます。

## 構成

```
src/
  main.js              シェル（ヘッダー、ステッパー、PC アプリ／AR グラスの枠、フッター、ガイドツアー）
  app/                 画面の登録・状態管理・ツアー用ヘルパー
  data/phantom.js      合成胸部ファントム（CT 値と 3D 形状を同じ定義から生成）
  data/cases.js        架空の症例・接続設定・端末
  three/               3D メッシュ生成（マーチングキューブ・チューブ）と Three.js ビューア
  ui/                  2D CT ビューア、共通 UI 部品
  screens/             各画面
  styles/              共通スタイルと画面ごとのスタイル
```

### 合成ファントムについて

CT 画像と 3D モデルは、実在の患者データを使わずに、楕円体やチューブなどの形で胸部（体表・肺・心臓・大血管・肺血管・気管支・肋骨・胸骨・椎骨・肝臓など）を定義して作っています。同じ定義から CT の値（HU）と 3D の形の両方を計算するので、2D 画像と 3D モデルの位置が一致します。デモ用のターゲットとして、右上葉に結節を 1 つ置いています。
